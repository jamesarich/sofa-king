# Sofa King

A self-hosted media center: live TV, recordings and media libraries on one server, and one app that watches them. Three Gradle builds: the app in `app/` (rules in `app/AGENTS.md`), the server in `backend/` (rules in `backend/AGENTS.md`) and the wire types both include in `contract/` (rules in `contract/README.md`). The root `settings.gradle.kts` only includes them for one IDE import; build each from its own directory. On the shared host, run `/home/james/.claude/bin/gradle-queue -C app --`, `-C backend --` or `-C contract --` from the repository root; anywhere else (CI, a container, a fresh machine) run `./gradlew` from `app/`, `backend/` or `contract/`. The layout, the shared catalog and convention plugins, version pins and Renovate: CONTRIBUTING.md#repository-layout and CONTRIBUTING.md#dependencies.

Run `./gradlew spotlessApply` before committing and fix detekt findings in the code; CONTRIBUTING.md#formatting-and-static-analysis has the suppression and catch-all rules. Check a docs change with `python3 docs/site/stage.py && mkdocs build --strict` (in a venv from `docs/site/requirements.txt`).

Run the checks for what you changed before you push, and push fixes together: a pull request is not where code first compiles. In a cloud container, `.claude/skills/cloud-build` says what builds there (the Android SDK, Maven Central's rate limit, the lint CLIs) and what only CI can check; `.claude/skills/ci-failure` reads a red run and lists the known flakes before a re-run; `.claude/skills/emulator-check` covers checks on an emulator or simulator, and turning one into a Maestro flow in `app/maestro/` that `tv-monkey.yml` runs every night.

`CLAUDE.md` in each part only imports its `AGENTS.md`; edit the `AGENTS.md`. Commits, pull requests and GitHub comments carry no AI attribution (no `Co-Authored-By` or session trailers, no "Generated with" footers); `.claude/settings.json` turns it off for Claude Code.

Commit scopes, pull requests and CI (which workflow runs on which change, snapshots and releases): CONTRIBUTING.md#commits, CONTRIBUTING.md#pull-requests and CONTRIBUTING.md#ci. A wire change goes in `contract/` with both sides in one pull request and never edits a fixture: CONTRIBUTING.md#wire-changes.

Language: write US English everywhere: docs, comments, UI copy, log messages, commit messages, pull requests, and the names of our own files, classes, functions and variables. Spell it color, behavior, center, gray, license, catalog, canceled and canceling, optimize, recognize and serialize, and say program (not programme), movie (not film) and while (not whilst). Names that belong to someone else keep their spelling: the XMLTV `<programme>` element and a third-party API's fields. Our own stored names move with a migration, as `V208__program_names.sql` moved `guide_programme` and the `cancelled` recording state.

Docs: where a page goes, the nav, and the rules for keeping pages short (one fact on one page, tables for three or more options, implementation detail in the architecture pages, a Mermaid diagram for a flow): CONTRIBUTING.md#documentation.
