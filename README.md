# Sofa King

Live TV from a Sofa King server on Android TV, Google TV, phones, desktops, iPhone and the web.

- [`app/`](app/README.md): the Kotlin Multiplatform client and its [documentation](app/docs/README.md).

The [`snapshot` prerelease](https://github.com/jamesarich/sofa-king/releases/tag/snapshot) has a build of every platform from the latest `main`. [CONTRIBUTING](CONTRIBUTING.md) covers the build, CI and conventions, and [SECURITY](SECURITY.md) how to report a vulnerability.
