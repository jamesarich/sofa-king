# Support

Sofa King is a hobby project with one maintainer, so answers come from the documentation first and from issues when it falls short.

## Find the answer

- The [documentation site](https://jamesarich.github.io/sofa-king/) searches every page.
- Server problems: [troubleshooting](backend/docs/troubleshooting.md), and [operations](backend/docs/operations.md) for a provider that stops working.
- App problems: [troubleshooting](app/docs/troubleshooting.md) and [usage](app/docs/usage.md).
- Terms such as source, lineup and break are in the [glossary](docs/README.md#glossary).

## Ask or report

Search the [open and closed issues](https://github.com/jamesarich/sofa-king/issues?q=is%3Aissue) first, then open one with the form that fits:

| Form | For |
| --- | --- |
| [Server bug report](https://github.com/jamesarich/sofa-king/issues/new?template=server-bug.yml) | The server, Plex or another client of the server misbehaves |
| [App bug report](https://github.com/jamesarich/sofa-king/issues/new?template=app-bug.yml) | One app platform misbehaves |
| [Native provider broken](https://github.com/jamesarich/sofa-king/issues/new?template=provider-broken.yml) | A built-in streaming service lists no channels or does not play |
| [Feature request](https://github.com/jamesarich/sofa-king/issues/new?template=feature-request.yml) | Something Sofa King does not do yet |

Remove tokens, provider URLs with credentials and private addresses from everything you paste. Report a security problem privately, as [SECURITY.md](SECURITY.md) describes, never in an issue.

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
